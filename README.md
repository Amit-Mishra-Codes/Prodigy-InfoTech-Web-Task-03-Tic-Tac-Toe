# Prodigy InfoTech Web Development Task 03 — Tic-Tac-Toe

A responsive Tic-Tac-Toe web application built with HTML, CSS, and JavaScript.

## Features
- Play with two players on the same device.
- Play against a computer opponent.
- Computer tries to win, blocks immediate player wins, and prefers the center/corners.
- Tracks wins for X, wins for O/computer, and draws.
- Highlights the winning combination.
- New Round and Reset Scores controls.
- Responsive layout for mobile and desktop.
- Keyboard-accessible buttons and live status messages.

## Files
- `index.html` — page structure and game board
- `styles.css` — responsive styling
- `script.js` — game rules, turn handling, scoring, and computer moves

## Run locally
Download or clone this repository, then open `index.html` in a modern web browser. No installation or build step is required.

## Deploy with GitHub Pages
1. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and `.gitignore` to the repository root.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, branch `main`, folder `/(root)`, and tap **Save**.
4. Wait a few minutes, then open the GitHub Pages URL shown on the Pages settings screen.
